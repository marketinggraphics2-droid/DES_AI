## Product Overview

IQ Link, formerly IQHub, is a middleware integration platform purpose-built for SAP Business One.

It acts as an intelligent bridge between SAP B1 and virtually any data source, including external databases, REST APIs, CSV/XML files, and other SAP B1 companies.

IQ Link helps businesses automate data movement, transform records, schedule integrations, track errors, and sync transactions across SAP Business One and third-party systems without relying on manual uploads or disconnected workflows.

## Features

## Integration Engine

The Integration Engine is the core of IQ Link. It allows users to configure how data moves from a source system to a target destination, including how fields are mapped, transformed, validated, and posted into SAP Business One or another connected system.

Feature

Details

Visual Field Mapping

Drag-and-drop-style wizard maps source columns to SAP target fields, including nested objects such as DocumentLines.ItemCode.

Transformation Modes

Direct, Custom (static/template values with {placeholder} substitution), SQL Lookup Query, Service Layer OData Query, Formula.

Operation Modes

Create (POST), Update (PATCH by key), Upsert (check-then-create-or-update).

Automatically creates missing master data (Projects, Warehouses, Distribution Rules, Payment Terms) before posting document

SQL ↔ HANA Translation

Supports automatic SQL Server to SAP HANA dialect translation for UserQuery migrations.

FormattedSearches Remap

Auto-remaps FMS QueryIDs between SAP companies by matching UserQuery descriptions.

## Error Handling & Retry

IQ Link includes configurable error handling and retry controls to help prevent failed integrations from disrupting the entire sync process.

Feature

Details

Error Policies

Stop on first error, Continue on error, Retry then stop

Configurable Retry

1–N retry attempts with 2-second delay between attempts

SAP Session Recovery

Automatic re-authentication on 401 (session expiry) without counting as a retry

Skip Synced Rows

Deduplication via sync log — never re-processes a previously successful row

Skip "Already Exists"

Optionally marks SAP "already exists" errors as synced to prevent infinite retry loops

## Frequently Asked Questions (FAQ)

What types of systems can IQ Link integrate with SAP Business One?

IQ Link can connect SAP B1 with a wide range of systems, including:

- Point-of-Sale (POS) software

- E-commerce platforms

- Warehouse Management Systems (WMS)

- CRM tools

- Custom legacy systems

If your software supports data exchange (via APIs, file-based imports, or database-level sync), it can likely be integrated through IQ Link.

How does IQ Link handle data inconsistencies between systems?

IQ Link features a built-in status report that flags mismatched or missing data in real time. This allows users to proactively correct issues before they affect operations or reporting, helping maintain data integrity across connected systems.

Is the integration done in real time or in batches?

IQ Link supports both real-time and scheduled (batch) data synchronization, depending on the needs and capabilities of the systems being integrated. Real-time syncing is ideal for operations like inventory or sales, while batch sync may suit reporting or legacy system updates.

Can IQ Link be customized to fit our unique system architecture?

Yes. IQ Link is highly adaptable and can be configured to match your specific business logic, field mappings, and data transformation requirements. Our team will assess your existing infrastructure and develop a custom integration plan that works for your operations.

How do we monitor or troubleshoot integration issues?

IQ Link includes a user-friendly dashboard where you can view integration logs, check status reports, and identify sync errors or delays. This transparency empowers your IT or operations team to quickly diagnose and resolve any issues.

How long does integration with IQ Link usually take?

The timeline depends on the number of systems being integrated and the complexity of their data structures. Simple one-way connections can be set up in a matter of days, while more complex bi-directional syncs may take several weeks.

How do we know if IQ Link is the right solution for our integration needs?

If you use multiple disconnected systems and want to centralize your data in SAP B1—or reduce the time spent on manual reconciliation—IQ Link is a smart solution. A consultation and system audit can help determine the best-fit integration strategy for your business.

Will integrating systems via IQ Link affect our current SAP setup?

No. IQ Link is designed to integrate without disrupting your existing SAP Business One configuration. It works alongside your current setup and enhances it by bridging data between platforms.
